# About connectMWP

connectMWP was created by Stefan Heinz to solve a very specific problem: the manual overhead of managing content publishing workflows for multiple WordPress websites.

## The Mission
Automating keyword research, article drafting, SEO tagging, featured image generation, and internal link building using modern AI models (like Claude Code) is incredibly powerful. However, standard WordPress connection tools often fail due to hosting security rules that strip credentials (a common issue on hosts like SiteGround or WP Engine).

connectMWP bridges this gap by providing:
1. A secure WordPress plugin that authenticates requests using custom headers, bypassing reverse-proxy strips.
2. A lightweight Model Context Protocol (MCP) server that runs locally on your computer via standard input/output.
3. Multi-site config mapping allowing you to manage 10+ sites from a single running AI context.
